# SAN2LAURE IA COMMERCE v1
MVP de gestion commerciale pour IGOSA SERVICES.

Inclus:
- tableau de bord
- catalogue produits
- commandes
- conversations
- endpoint webhook WhatsApp prêt
- configuration .env

Installation:
1. Installer Node.js 20+
2. `npm install`
3. copier `.env.example` vers `.env`
4. `npm start`
5. ouvrir http://localhost:3000

La connexion réelle à WhatsApp Business Platform devra être configurée avec les identifiants Meta du propriétaire.
